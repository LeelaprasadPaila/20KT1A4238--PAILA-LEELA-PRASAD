# ⚖️ 10. Bias-Variance Trade-off

The internship introduced the relationship between model complexity and generalization.

### Underfitting

A model is too simple to capture the underlying patterns in the data.

### Overfitting

A model learns the training data too closely and performs poorly on unseen data.

### Bias-Variance Trade-off

Understanding the balance between **bias, variance, model complexity, and generalization error** is important when selecting and tuning machine learning models.

# 📈 Classification Metrics

### Accuracy

```text
Accuracy = (TP + TN) / (TP + TN + FP + FN)
```

Measures the proportion of correctly classified observations.

### Precision

```text
Precision = TP / (TP + FP)
```

Measures how many predicted positive observations are actually positive.

### Recall

```text
Recall = TP / (TP + FN)
```

Measures how many actual positive observations were correctly identified.

### F1 Score

```text
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

The F1 score provides a balance between precision and recall.

### ROC-AUC

ROC-AUC evaluates classification performance across different decision thresholds.

# 🚧 Common Machine Learning Challenges

| Challenge       | Possible Approach                                                      |
| --------------- | ---------------------------------------------------------------------- |
| Overfitting     | Regularization, cross-validation, early stopping, ensemble methods     |
| Underfitting    | Increase model complexity or improve feature representation            |
| Imbalanced Data | Stratified validation, class weighting, appropriate evaluation metrics |
| Feature Scaling | Standardization or normalization where appropriate                     |
| High Variance   | Regularization, simpler models, or additional training data            |
| High Bias       | Improve features or increase appropriate model complexity              |
| Slow Training   | Optimize the workflow and use suitable computational resources         |

# ✅ Best Practices

The following machine learning practices were emphasized during the program:

1. Split data into training and testing sets.
2. Use cross-validation when appropriate.
3. Apply feature scaling when required by the algorithm.
4. Start with a simple model before increasing complexity.
5. Select evaluation metrics according to the problem.
6. Monitor models for overfitting and underfitting.
7. Keep code organized and documented.
8. Compare multiple suitable algorithms.
9. Tune hyperparameters systematically.
10. Evaluate final models using unseen data.
